# Security Policy

MyNotch changes Windows settings (taskbar, theme, Explorer icons) and keeps backups so every change can be undone.
Bugs that could lose those backups or change the system without the user's consent are treated as security issues.

## Reporting a vulnerability

Please **do not open a public issue**. Use [private vulnerability reporting](../../security/advisories/new)
(Security tab → "Report a vulnerability"). You will get a reply within 7 days.

## Supported versions

Only the latest release receives fixes.
